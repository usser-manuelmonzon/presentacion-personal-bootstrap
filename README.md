# Página de Presentación Personal con Bootstrap 5

## Objetivo del proyecto

Desarrollar una página web de presentación personal utilizando HTML5, Bootstrap 5 y CSS personalizado. El sitio presenta información sobre mi formación, habilidades, proyectos y visión profesional mediante un diseño responsive y accesible.

## Cómo ejecutar la página

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` directamente en el navegador o utilizar la extensión Live Server.
4. Verificar el funcionamiento de la página en diferentes tamaños de pantalla.

## Componentes de Bootstrap utilizados

- Navbar responsive.
- Sistema Grid mediante `container`, `row` y `col`.
- Cards para presentar los proyectos.
- List Group para mostrar las habilidades.
- Badges con estilo `rounded-pill`.
- Clases de espaciado, alineación, sombras y tipografía.

## Elementos personalizados mediante CSS

- Colores principales del sitio.
- Tipografía y tamaños de texto.
- Espaciados internos y externos.
- Fotografía de perfil circular.
- Diseño de las tarjetas de proyectos.
- Efectos de transición al pasar el cursor.
- Estilos del pie de página.
- Ajustes responsive para teléfonos y tabletas.

## Principales decisiones de diseño

Se utilizó una combinación de azul oscuro, blanco y gris claro para mantener una apariencia profesional. El encabezado conserva una distribución horizontal entre la información personal y la fotografía. Los proyectos se muestran en una tarjeta por fila para presentar las imágenes completas y evitar recortes. También se realizaron ajustes específicos para las vistas de 320 px, 768 px y 1280 px, evitando el desplazamiento horizontal.
